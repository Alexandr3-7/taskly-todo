# Taskly · список задач

Адаптивный To-Do List для тестового задания **The Digital (Vibe Coder)**. Приложение запускается в браузере без регистрации, бэкенда и сборки.

**[Открыть демо](https://alexandr3-7.github.io/taskly-todo/)**

## Что работает

| Требование | Как проверить |
| --- | --- |
| Добавление | Введите название и нажмите «Добавить» или Enter |
| Выполнение | Нажмите галочку. Повторное нажатие вернёт задачу в активные |
| Удаление | Нажмите корзину. Последнее удаление можно отменить из уведомления |
| Сохранение | Обновите страницу: задачи и их статус сохранятся |

Дополнительно: фильтры, счётчик и круг прогресса, очистка выполненных, пустые состояния, клавиатурное управление и мобильная вёрстка. При добавлении задачи в фильтре «Выполненные» приложение переключается на «Все», чтобы новая задача сразу была видна.

## Как запустить

Откройте `index.html` в браузере. Для проверки сохранения на стабильном локальном адресе запустите из корня проекта:

```bash
python -m http.server 8000
```

Затем откройте [localhost:8000](http://localhost:8000).

## Технические решения

- **HTML, CSS, JavaScript без зависимостей во время работы.** Для такой задачи отдельный фреймворк и сборка не нужны.
- **Хранение:** `localStorage` по ключу `taskly.tasks.v1`, без передачи данных на сервер. Список не синхронизируется между устройствами; при очистке данных сайта он исчезнет. Если сохранение заблокировано, приложение продолжает работать до перезагрузки и явно предупреждает об этом.
- **Ввод:** пустые названия не сохраняются, длина ограничена 160 символами. Названия вставляются через `textContent`, а не как HTML.
- **Структура:** `index.html` — разметка, `styles.css` — адаптивные стили, `app.js` — состояние, действия и отрисовка; `assets/` — иконка приложения.

**ИИ-инструмент:** ChatGPT использовался для проектирования интерфейса, реализации и подготовки проверок.

## Проверки

Логика, без установки зависимостей:

```bash
node tests.js
```

Браузерные сценарии: первый запуск, добавление кнопкой и Enter, выполнение, сохранение после перезагрузки, фильтры, отмена удаления и отсутствие горизонтальной прокрутки при ширине 320, 390 и 1440 px.

```bash
npm install
npx playwright install chromium
npm run test:browser
```

Для установленного Chromium можно передать `CHROMIUM_PATH`. Чтобы обновить скриншоты, задайте `UPDATE_SCREENSHOTS=1` при запуске браузерных тестов.
